# Roteiro de testes com colegas

Use este roteiro com cinco colegas. Cada pessoa deve preencher um laudo individual baseado no modelo de qualidade.

| ID | Cenário | Resultado esperado |
|---|---|---|
| CT-01 | Abrir a página inicial | A apresentação, categorias e produtos disponíveis são exibidos corretamente. |
| CT-02 | Filtrar uma categoria | Apenas produtos da categoria selecionada permanecem visíveis. |
| CT-03 | Acessar o painel sem login | O sistema direciona para a tela de login. |
| CT-04 | Entrar com credencial correta | O painel de produtos é apresentado. |
| CT-05 | Entrar com senha incorreta | O sistema mostra uma mensagem de erro, sem permitir o acesso. |
| CT-06 | Cadastrar produto válido | O produto aparece no painel e no cardápio público quando disponível. |
| CT-07 | Editar produto | A alteração aparece no painel e no catálogo público. |
| CT-08 | Alterar disponibilidade | Produto indisponível deixa de aparecer na página pública. |
| CT-09 | Excluir produto | Produto deixa de aparecer no painel e no catálogo. |
| CT-10 | Testar em tela pequena | Navegação, formulário e catálogo permanecem legíveis e utilizáveis. |

Registre a evidência de cada teste (captura de tela ou anotação objetiva), a data, o dispositivo/navegador e a decisão tomada para cada sugestão.
